Excess Baggage Calculator is an Android mobile application developed using Java and XML in Android Studio. It helps users estimate excess baggage fees based on baggage weight, ticket class (Economy or Business), and the excess baggage rate per kilogram. The application calculates the excess baggage weight, total charge, and 8% service tax to display the final amount payable. It also includes a user-friendly interface, an About page with developer information and a sharing feature to share the application link.
